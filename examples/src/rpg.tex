\RPGChapter{RPG Bundle Example}[One package loading the full toolkit]

The \texttt{rpg} bundle loads the color, font, layout, sectioning, table,
skill-tree, and panel modules together.  This document uses only
\texttt{\string\usepackage\{rpg\}} and then exercises the bundled APIs.

\RPGSection{Bundle Options}[Theme, alignment, and columns]

The package options selected the \texttt{arcane} color theme, ragged-right body
text, RPG body fonts, tightened list spacing, and a two-column page layout.
The visible text styles here come from semantic wrappers such as
{\RPGFontTerm term text}, {\RPGFontDice 2d6+3}, and
{\RPGFontCode \string\RPGFontCode}.  The same semantic colors feed the panels,
tables, and headings below.
