\chapter[Class Example]{The Obsidian Gate}[Standard commands with RPG styling]

The \texttt{rpgbook} class loads the RPG toolkit, applies book-oriented RPG
defaults, and maps ordinary sectioning commands onto RPG heading styles. This
chapter was created with \texttt{\string\chapter}, not
\texttt{\string\RPGChapter}.

\section[Command Mapping]{Mapped Section Commands}[Short titles still work]

The standard short-title form is preserved for table-of-contents entries:

\begin{verbatim}
\section[Command Mapping]
    {Mapped Section Commands}
    [Short titles still work]
\end{verbatim}

The final optional argument is an \texttt{rpgbook} extension that supplies the
RPG subheading text.
